# 참호 속으로 — 1차 세계대전 선택형 시뮬레이션

학생이 1차 세계대전 속 병사 또는 후방의 여성이 되어 선택을 내리고, 그 결과를 영상과 함께 체험하는 역사 수업용 웹앱입니다.

## 구성
- `index.html` — 앱 전체 (이 파일 하나로 동작)
- 장면 내용: 구글 시트 '장면' 탭을 웹에 게시한 CSV에서 읽어 옵니다. 시트를 고치면 새로고침만으로 반영됩니다.
- 영상: 이 저장소의 `videos` 폴더 (장면 ID 이름, 예: `videos/P01.mp4`)

## 개인정보
- 학생의 답은 서버나 시트에 저장되지 않습니다.
- 답은 학생 브라우저 안에만 모였다가, 학생이 직접 'PDF로 저장'해서 담당 선생님께 제출합니다.
- 브라우저 창을 닫으면 답은 사라집니다.

## 설정 (`index.html` 위쪽)
- `SHEET_CSV_URL` — '장면' 탭을 [파일 → 공유 → 웹에 게시 → CSV]로 게시한 주소
